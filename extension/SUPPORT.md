# Support

Use [GitHub Issues](https://github.com/wrestle-R/multi-codex/issues) for bug reports and feature requests.

Include your operating system and CPU architecture, VS Code version, official Codex extension version, and the steps needed to reproduce the problem. This pre-release targets local Linux x64 and macOS 26+ on Apple Silicon and Intel. Check the README's compatibility and activity-guard limits first.

Do not attach credentials, auth JSON files, access or refresh tokens, private conversations, or account-store contents. Review any diagnostic output before sharing it.
