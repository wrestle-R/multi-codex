## Distribution and future validation

1. v1.3.5 is published using the existing tested assets, with unsigned Mac distribution explicitly documented and installer scripts included in `SHA256SUMS`.
2. `check:release-gates` and the publication workflow require passed Linux/Mac builds, installer verification, authenticated account isolation and all six matching asset hashes. Developer ID signing and notarization are not publication gates. `check:release-gates -- --full-validation` additionally checks the broader functional matrix; it never requires Apple credentials.
3. Keep unfinished validation open and record environment, tester, timestamp, evidence and matching artifact SHA-256 as it is completed. Preserve profile directories and credentials during upgrades; keep the local backup available for rollback.

The normal [update script](../../scripts/update-app.sh) follows the latest public release. v1.3.5 includes both install/update scripts as release assets so README commands download scripts matching the published packages. Mac users explicitly opt into the checksum-verified unsigned build; the installer leaves first-open approval to macOS. The local v1.3.5 installation was updated from the verified candidate directly. The completed tests have the scope described above.
