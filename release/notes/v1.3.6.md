# Multi Codex v1.3.6 — CLI launches for saved accounts

Launch an account in the Codex CLI from its account row. The terminal uses the account's isolated Codex and SQLite homes and the selected project folder. Inherited credential overrides are cleared, and deletion or cache cleanup is blocked while the CLI uses the account.

Accounts now appear in plan order: Pro, Plus, Go, then Free. Usage refreshes automatically at startup, with the last saved usage visible while a refresh is running or unavailable. Choose Sage, Ocean, Sand, Rose, Plum or Orange in the theme picker, with light and dark support.

Updated launch buttons use app logos and explicit labels. The launcher starts maximized with a normal restore size; Hyprland retains window decorations. README screenshots show the updated accounts and workspace views.

Saved accounts, credentials, conversations, profile paths and launch preferences are preserved during updates. The updater verifies the downloaded package checksum before replacing the application.

Packages: Linux x86_64 AppImage, DEB and RPM; Apple Silicon macOS 26+ DMG. The Mac package has no Apple Developer ID signature or notarization and requires the README's explicit unsigned-install opt-in and macOS first-open approval.

Release verification and its limits are recorded in the [validation manifest](https://github.com/wrestle-R/multi-codex/blob/main/release/evidence/v1.3.6-validation.json). Authenticated standalone isolation evidence is carried forward from v1.3.5 for the unchanged desktop version allowlist; this release also checks native launch and profile guards. Broader distribution and desktop validation remains pending.
