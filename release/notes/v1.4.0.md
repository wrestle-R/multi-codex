# Multi Codex v1.4.0

Windows x64 support for the desktop launcher and companion VS Code extension, account actions in the macOS menu bar, all-account extension usage refresh, and persistent launcher maximization across desktop changes.

The matching extension is v0.2.0. Download the VSIX for Linux x64, macOS arm64/x64, or Windows x64. Package filenames derive from the extension manifest.

## Changes

- Native Windows account storage, protected file ACLs, credential-store integration, executable discovery, VS Code and terminal launches, NSIS installer, and PowerShell install/update scripts.
- Windows extension uses authenticated named pipes and a native executable bridge; desktop and extension share accounts and account locks.
- Extension toolbar checks every saved account with bounded concurrency, progress, reset times, and independent error handling.
- macOS menu bar lets you select an account and open installed supported launch targets. Closing the window keeps the app running; Quit exits it.
- The Hyprland launcher preserves its tiled maximized state after focus and desktop changes.
- The website is the primary documentation source. README links there; release metadata is under release/ and docs/ is untracked.

## Validation

Candidate validation is in progress. Do not publish until native CI, packaged VSIX tests, and installer/isolation gates pass for the exact release assets.

Initial Windows scope is native x64. WSL/Remote SSH and Windows virtual-desktop placement are deferred. Standalone Windows Codex isolation must pass its exact-version verification before it is enabled.
