# Multi Codex v1.3.8 — Launch settings and terminal picker improvements

## Changed

- Split Launch settings into Workspace and Launching sections, with Save and Cancel always visible while advanced options scroll.
- Show Automatic and supported installed terminals in the CLI terminal picker, with a selected checkmark and keyboard navigation.
- Keep saved preferences when a terminal is removed, and explain how to choose an installed replacement. Preferences change only when saved.

## Compatibility

Linux x86_64 packages: AppImage, DEB and RPM. Apple Silicon Mac: macOS 26 or newer. The Mac package is unsigned and unnotarized; the installer requires explicit unsigned-install opt-in. Existing accounts, credentials, conversations and saved launch preferences are preserved by the installer.

## Downloads and verification

Use the matching install or update script from the [latest release](https://github.com/wrestle-R/multi-codex/releases/latest). Package and installer validation is tracked in the [release manifest](https://github.com/wrestle-R/multi-codex/blob/main/docs/releases/v1.3.8-validation.json). Broader platform checks are tracked separately.
