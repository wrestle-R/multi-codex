# Multi Codex v1.8.2

This maintenance release updates security-sensitive dependencies and tidies the repository while preserving account and conversation storage.

## Security updates

The website upgrades Next.js to a patched 16.4 release. Desktop build and test dependencies receive compatible security updates. Native dependency fixes include Rustls, certificate verification/root data, constant-time utilities and Tokio.

Windows updates continue using signed EXE installers. Legacy ZIP extraction is disabled on Windows; Mac keeps the archive support its signed app updates require. Native installer and signed-updater acceptance/refusal checks must pass before publication.

Dependency advisories do not establish that a deployed installation was exploited. Some older GTK ecosystem dependencies still have upstream advisory or maintenance warnings; the audit record explains the remaining scope rather than claiming the entire dependency graph has no warnings.

## Repository organization

Old working plans have moved out of the tracked source tree. Contributor guidance maps each part of the project, and the tracked-file check now rejects private local notes. Published release evidence remains available.

## Install and update

Use the same [install link](/install) for Linux x64, Windows x64 and Apple Silicon Macs on macOS 26+. The page suggests a package and offers a manual computer picker. Existing installations can use the launcher’s Update button.

Mac receives v1.8.2 without T3. T3 desktop launching remains available on Linux and Windows. This release does not install or modify your Codex, VS Code or T3 applications.

## Validation

Exact package hashes, native runner checks and remaining limitations are recorded in the [release evidence](https://github.com/wrestle-R/multi-codex/blob/main/release/evidence/v1.8.2-validation.json). The [audit record](https://github.com/wrestle-R/multi-codex/blob/main/release/evidence/v1.8.2-audit.json) lists the dependency findings and their disposition.
