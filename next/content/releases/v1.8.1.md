# Multi Codex v1.8.1

All supported platforms receive v1.8.1. Linux and Windows include T3 Code desktop launching; Mac includes the existing Multi Codex launcher without T3.

## Normal updates restored

The original updater cannot identify its platform. v1.8.0 shipped only Linux and Windows packages, so its legacy feed was held on v1.7.5. That prevented older Linux and Windows apps from finding v1.8.0 too.

v1.8.1 supplies signed packages for all supported platforms. The legacy feed now selects the newest complete release, allowing older installations to find this update through the normal Update button. Platform-specific feeds continue working for v1.8.0 users. A manual installer is no longer required solely to cross that version gap.

## Mac support

Multi Codex supports Apple Silicon Macs running macOS 26 or newer. Existing Codex desktop, VS Code, CLI, accounts, usage and Orbit features remain available. This release does not add Intel or older-macOS desktop packages.

Only T3 account launching is disabled on Mac. T3 currently resets its Electron profile into the shared macOS application-data directory. The launcher has not yet verified a safe per-account routing solution there, so it does not offer that target. This does not mean the rest of Multi Codex is unsupported on Mac.

Mac downloads and updates receive v1.8.1, without the T3 button. The older v1.7.5 and v1.8.0 releases remain unchanged.

## Validation

Native Linux, Windows and Apple Silicon Mac package, installer and signed updater checks must pass before publication. Existing account and conversation data stays in place. T3 startup checks use disposable profiles on Linux and Windows, without real account sign-ins or an authenticated agent turn.

Exact source, completed checks and asset hashes are recorded in the [validation evidence](https://github.com/wrestle-R/multi-codex/blob/main/release/evidence/v1.8.1-validation.json).
