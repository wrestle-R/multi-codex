# Multi Codex v1.7.2

Orbit keeps two recent chat shortcuts per saved account. They come from Codex’s local conversation index, remain visible while idle and do not depend on typing, generation or selected-chat detection. Archived chats and background subagent conversations are excluded. A legacy “has user event” flag does not hide otherwise valid saved chats. Clicking a shortcut navigates to its exact conversation in the correct account’s Desktop app. These are recent conversations, not a claim that both chats are currently open. If the local index is temporarily unavailable, the last saved shortcuts remain visible with an availability notice.

Opening Codex Desktop no longer asks for a project folder or sends an open-project request. VS Code and CLI retain their project-folder selection. Existing VS Code window shortcuts and CLI discovery remain available; ambiguous terminal navigation reports an error instead of focusing a different window.

Idle Orbiters are still. Working activity uses a small optional pulsing status dot instead of continuously animated plush avatars. Attention reminders use a static icon and account name. Equal avatar identities are reused across refreshes to avoid unnecessary canvas drawing.

This release is **Stable**. Use the launcher’s **Update** button to install it. Existing accounts, credentials and running clients are preserved. Live activity and attention indicators require a connected managed client; recent shortcuts do not require that connection.

Native package validation is recorded in the [release evidence](https://github.com/wrestle-R/multi-codex/blob/main/release/evidence/v1.7.2-validation.json). Orbit supports macOS and supported Linux Wayland desktops; Windows retains launcher/editor/updater support. macOS 27 and every terminal/window-manager combination remain unverified. Mac bundles are ad-hoc signed, without Developer ID or notarization.
