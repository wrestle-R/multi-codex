# Multi Codex v1.8.10

## Orbit

Orbit skips redraws and input-region updates when its view stays the same. Account, chat and attention changes still refresh on the existing schedule.

## Account launches and updates

Private desktop, CLI and editor-extension launches clear inherited Codex provider overrides. The native updater matches the GitHub release asset to the platform and version, checks the bundled signing key and holds the install lock through restart.

## Downloads

Use the [install page](/install) or the Update button. The release ZIP groups the individual installers, update signatures and checksums.
