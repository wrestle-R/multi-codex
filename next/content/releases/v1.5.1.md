# Multi Codex v1.5.1

Update discovery now runs quietly when the launcher starts, when you refresh an account or all accounts, when you return to the app, and when the connection comes back. While the app is visible, it also checks every 15 minutes.

The **Update** button appears only when a newer signed stable release is available for your installation. Background connection failures do not open a popup or interrupt account use. A previously discovered update stays available if a later check fails, and the next refresh retries discovery.

Click **Update** to download, verify and install the release. Download progress, installation and restart remain visible. Installation waits for the progress listener, prevents duplicate updates and preserves saved accounts and profile data. An explicit installation failure offers a retry.

In-app installation supports Linux x64 AppImage, Apple Silicon macOS app bundles and Windows x64 installers. Linux `.deb` and `.rpm` installations use their package manager. Platform requirements and Codex Desktop compatibility are unchanged.

The release feed and update payloads retain signature verification. See the [storage and updates guide](/docs/storage-and-updates) for details.
