# Multi Codex v1.2.0

## Multi Codex v1.2.0

### Hyprland launch flow
- Opens Multi Codex as a centered floating 1180×760 window without changing Hyprland configuration.
- Starts folder selection at `~/Desktop/code`, falling back to the home directory.
- Adds a launch destination chooser for the current desktop or Hyprland desktops 1–10.
- Moves only the newly launched VS Code window and follows it to the chosen desktop, while leaving VS Code open with a warning if movement fails.

### Usage and storage
- Shows reset-credit expiry details, titles, descriptions, and status when Codex reports them, with an explicit fallback when only a count is available.
- Adds a clickable storage breakdown sorted by profile size, including total, reclaimable cache, and unassigned app data.
- Adds guarded per-profile cache cleanup that preserves credentials, conversations, archived sessions, settings, workspaces, skills, plugins, and installed extensions.
- Refuses cache cleanup while a profile is running and keeps full profile deletion behind explicit confirmation.

### Interface and documentation
- Replaces the three-state theme cycle with persisted Light/Dark behavior, circular reveal animation, reduced-motion fallback, matching icons, and the `D` shortcut outside editable fields.
- Refreshes README features and screenshots using synthetic demo profiles only.

### Verification
- 32 frontend tests and 44 Rust tests passed.
- Production build, secret scan, release packaging checks, Linux AppImage/DEB/RPM packaging, and macOS universal DMG smoke tests passed.
