# Multi Codex v1.7.5

## Keep Codex available after updates

Codex Desktop updates no longer hide the **Open Codex** button. Multi Codex accepts any installed Codex desktop version on its supported platforms, including builds whose version metadata cannot be read. The main window, tray menu and Launch settings all use the same installed-app check.

Previous releases allowed only a small list of exact Codex builds. A newer build could therefore be installed and working while Multi Codex hid it with an account-isolation verification message. This release removes that version restriction.

## Your accounts stay in place

Each account keeps its existing Codex home, desktop-data directory, credentials and conversations. Launches continue to set separate account and Electron storage paths. This update does not migrate or reset your saved account data.

Use the launcher's **Update** button, then open Codex from the account you want to use.

## Compatibility and validation

Accepting all version numbers does not mean every past or future upstream build has been tested. Authenticated refresh/logout isolation was not tested for the newly enabled Codex builds. Multi Codex retains its account-directory isolation and executable discovery checks.

Platform requirements remain Apple Silicon macOS 26+, Linux x64 and Windows x64. Windows Orbit is unsupported. Mac packages are ad-hoc signed without Developer ID/notarization; macOS 27 remains unverified.

The release also refreshes extension packaging dependencies. Native package, installer and signed-updater results are recorded in the [release evidence](https://github.com/wrestle-R/multi-codex/blob/main/release/evidence/v1.7.5-validation.json) and the [native release workflow](https://github.com/wrestle-R/multi-codex/actions/runs/41459473103).
