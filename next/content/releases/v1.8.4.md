# Multi Codex v1.8.4

## Linux launch destinations

T3 now offers the same Linux desktop chooser as Codex. CLI opens the folder picker first, then lets you choose a desktop. Failed placement can be retried without opening another app window. The existing setting to hide the desktop chooser still applies.

Konsole launches in a separate process and XFCE Terminal disables its shared server so the launcher can identify the account window. Terminals whose shared processes cannot be identified safely report a placement error instead of moving an unrelated window.

## Buttons that fit

VS Code, T3, CLI and Codex buttons fit their labels instead of sharing a fixed width. They wrap when space is limited.

## Install and update

Use the [install link](/install), or the Update button in Multi Codex. Existing account and chat storage stays in place. Linux and Windows support T3; Mac requires Apple Silicon and macOS 26 or later and retains its existing launchers without T3.

## Validation

Local frontend tests (142), production frontend build, native Rust check and focused terminal/placement tests passed before tagging. A disposable Konsole window was identified on Hyprland. Live T3 placement has not been directly verified. Native release, installer and signed-updater gates must pass before publication.
