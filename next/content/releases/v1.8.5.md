# Multi Codex v1.8.5

## Keep the Mac menu bar running

Closing the launcher with the red button or Command-W hides its window and keeps Multi Codex running in the menu bar. Reopen the launcher from the menu bar or Dock. Choosing Quit still exits the app, and update restarts remain available.

## Install and update

Use the [install link](/install), or the Update button in Multi Codex. Mac requires Apple Silicon and macOS 26 or later. The Mac app is ad-hoc signed, and macOS may ask you to approve it on first open. Linux and Windows retain their launchers and T3 support.

## Validation

The [close-to-tray regression check](https://github.com/wrestle-R/multi-codex/pull/7) reproduced the automatic exit and passed with the fix. The packaged app passed repeated close and reopen cycles on macOS 26.7.2, including reopening from both the menu bar and Dock. Menu-bar Quit, Dock Quit and Command-Q exited cleanly. Confirmation on the reporter's macOS 27 setup is pending.

Native installer and updater checks passed on macOS, Linux and Windows. The update tests used disposable installations and verified that the native updater rejected invalid payloads. The release asset checksums, updater manifest and all three update payload signatures were verified. See the [release workflow](https://github.com/wrestle-R/multi-codex/actions/runs/45252811859).
