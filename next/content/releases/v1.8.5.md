# Multi Codex v1.8.5

## Keep the Mac menu bar running

Closing the launcher hides its window and keeps Multi Codex running in the menu bar. The app now prevents the automatic exit request that can follow the last window closing. Reopen the launcher from the menu bar. Choosing Quit still exits the app, and update restarts remain available.

## Install and update

Use the [install link](/install), or the Update button in Multi Codex. Existing account and chat storage stays in place. Mac requires Apple Silicon and macOS 26 or later. Linux and Windows retain their existing launchers and T3 support.

## Validation

The macOS regression check for [PR #7](https://github.com/wrestle-R/multi-codex/pull/7) reproduced the previous automatic-exit failure and passed with the fix. It covers close, reopen, tray persistence and explicit Quit. This does not establish that the reporter's exact macOS 27 environment has been retested.

Native package, installer and signed-updater release gates are pending. This candidate is not published yet.
