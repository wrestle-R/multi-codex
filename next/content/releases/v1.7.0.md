# Multi Codex v1.7.0

**Orbit** adds a small desktop companion strip. Every account has a permanent **Orbiter**. Live Codex Desktop sessions appear as dots; hover for usage and session details, then click to return to the correct account and chat. Questions, approvals and possible requests for help receive quiet visual reminders. More than four chats use an overflow control.

Turn Orbit off in **Settings**. Adjust Orbiter size, opacity, display, position, motion and optional sound under **Orbit**. Orbit hides during fullscreen, and closing the launcher keeps its tray and companions running. Explicit Quit still exits the app.

Shared conversations now retain complete native history and attachment paths across account handoff. Model settings, names, queued messages and archive actions use the appropriate native routes, with durable recovery when catalog updates fail. Mac chat navigation verifies the running account before opening a chat, avoiding credential access during warm navigation.

After updating and relaunching, existing installations show a minimal **What’s new** view once. Dismiss it with **Got it**; the bottom version label lets you reopen it later. Fresh installations start with onboarding.

## Update

Use the launcher's **Update** button. Signed packages preserve accounts and profile data and restart only Multi Codex. Open Codex and VS Code sessions stay running. Existing Desktop instances started before the update begin reporting Orbit activity on their next managed launch.

Linux x64, Apple Silicon macOS 26+ and Windows x64 use the release packages. Orbit is available on macOS and Linux Hyprland, GNOME and KDE; Windows keeps its account launcher and shared-chat support. Mac bundles are ad-hoc signed; Apple Developer ID and notarization are not configured.

## Verification and limits

The shared backend and Orbit source received native Linux, Windows, Mac, Hyprland, GNOME and KDE checks before this release. Release package, installer and signed updater results are recorded in the [validation evidence](https://github.com/wrestle-R/multi-codex/blob/main/release/evidence/v1.7.0-validation.json).

The reported macOS27 close-button issue was not reproduced on the macOS 26.6.2 runner. Native close/reopen cycles retain the process and menu-bar icon; Dock Quit exits deliberately. Linux distro coverage is limited to the recorded native environments. Orbit observes managed Codex Desktop sessions, not VS Code or CLI conversations.
