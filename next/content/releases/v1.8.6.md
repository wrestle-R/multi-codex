# Multi Codex v1.8.6

## Keep the menu bar after Dock Quit

On Mac, choosing Quit from the Dock or pressing Command-Q hides the launcher and keeps Multi Codex running in the menu bar. Reopen it from the Dock or menu bar. To exit fully, choose Quit Multi Codex from the menu bar. Update restarts remain available.

## Install and update

Use the [install link](/install) or the Update button. Mac requires Apple Silicon and macOS 26 or later. The Mac app is ad-hoc signed. Developer ID signing and notarization are not configured. Linux and Windows behavior is unchanged.
