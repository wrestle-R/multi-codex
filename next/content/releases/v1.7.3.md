# Multi Codex v1.7.3

So the launcher was getting a little too attached to being the biggest window on the desktop. This update gives it some manners, clears up the header and gives the Orbiters a little more personality.

## One launcher, one tray icon

Opening Multi Codex again brings the existing launcher forward. The extra process exits before starting account services, Orbit or another tray icon. This applies to Linux, macOS and Windows. Closing the launcher window on Linux or macOS still keeps the tray running; use **Quit** to exit it. After quitting, you can open it normally again.

The guard applies once this version is running. Copies of an older release already running do not know about the guard; quit those old launchers normally before opening the updated app. Running Codex and VS Code account windows are separate and can stay open.

## A window that behaves like a window

Multi Codex opens maximized. After that it respects resizing, minimizing and switching to another app. The Hyprland loop that repeatedly forced its window back into a maximized state is gone, along with automatic maximization on every focus event. Opening Codex, VS Code or a terminal leaves the launcher's window state alone. Orbit keeps its separate overlay behavior.

## A bit more room

The header keeps the light/dark toggle, refresh, Settings and Add account visible. Update remains visible when a new release is available. Open **Settings** for appearance swatches and three separate destinations: **Orbit**, **Launch settings**, and **Storage**, with the current storage total beside it. Each opens its own dialog, so there isn't a giant pile of controls in the menu.

Orbit settings now open in the centered modal layer. Checkboxes have clearer switch styling, the display selector matches the rest of the app, size presets visibly show the current choice, and keyboard focus includes the display selector.

## Colours and companions

The slow circular light/dark reveal is gone from both the launcher and website. Mode changes apply immediately. Midnight, Coffee and Graphite join the launcher's six existing palettes. The website adds Ocean, Sand, Rose, Midnight, Coffee and Graphite alongside Sage, with its own saved palette preference.

The three new app palettes stay in the app's own saved preferences, so an older installed Multi Codex CLI can still read its shared settings. Existing palette choices retain their shared-settings behavior.

Existing Orbiters keep their assigned shape, colour and seed. Their seed now also picks accessories such as a beanie, beret, crown, glasses or headphones. They have mouths and slightly brighter lighting, while idle avatars remain still and reuse their drawing across unchanged refreshes.

## Updating and compatibility

This release is **Stable**. Use the launcher's **Update** button. Choose Stable or All updates under **Settings → Launch settings → Release channel**. Saved accounts, credentials and chat history stay in place. This release keeps the existing platform requirements: Apple Silicon macOS 26+, supported Linux packages and Windows x64. Orbit remains available on macOS and supported Linux Wayland desktops. Mac packages are ad-hoc signed, without Developer ID or notarization; macOS 27 remains unverified.

The [release evidence](https://github.com/wrestle-R/multi-codex/blob/main/release/evidence/v1.7.3-validation.json) records exact asset hashes, native installer and signed updater checks, and packaged Linux/macOS duplicate-launch checks. The frontend palette correction uses fresh app packages; unchanged native and editor checks are identified separately. Windows duplicate-launch runtime behavior and every desktop, terminal, monitor and DPI combination are not comprehensively verified. The installed local launcher’s Update button was not exercised for this release.
