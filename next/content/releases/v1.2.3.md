# Multi Codex v1.2.3

Multi Codex 1.2.3 adds a built-in workspace folder picker. Launch opens a modal over the full-screen app, starts in ~/Desktop/code when available, and hands the chosen folder to the existing Hyprland desktop chooser. The folder browser is read-only and does not open Dolphin or another file manager.

Also includes profile storage breakdown and safe cleanup controls, reset-credit expiry details when reported by Codex, and theme and account-limit improvements. Existing profiles and credentials are preserved during app updates.
