# Multi Codex

Launch multiple Codex accounts in isolated VS Code windows without changing your current login.

![Multi Codex light](tauri/public/light_screenshot.png)

![Multi Codex dark](tauri/public/dark_screenshot.png)

## Arch Linux

Install and launch:

```bash
curl -fsSL https://raw.githubusercontent.com/wrestle-R/multi-codex/main/scripts/install-app.sh -o /tmp/install-multi-codex.sh
bash /tmp/install-multi-codex.sh
```

[Download for Arch Linux](https://github.com/wrestle-R/multi-codex/releases/download/v2.2.1/Multi.Codex_2.2.1_amd64.AppImage)
