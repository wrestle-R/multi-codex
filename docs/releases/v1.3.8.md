# Multi Codex v1.3.8

Launch settings now has clearly separated Workspace and Launching sections, more breathing room, and a scrollable body with Save and Cancel always in view. Executable paths and Codex home remain under Advanced.

The CLI terminal picker now matches the app’s colors in light and dark mode. It shows Automatic and only the supported terminals installed on this device, with an installed count and a checkmark for the current choice. Use arrows, Home/End, typing, Enter and Escape to operate the menu with a keyboard.

If a saved terminal has been removed, the picker keeps that preference and explains how to choose an installed replacement. Unavailable terminals do not clutter the dropdown, and preferences are changed only when you save.

Existing account IDs, credentials, conversations, folders and executable paths are preserved. Packages: Linux x86_64 AppImage, DEB and RPM; Apple Silicon macOS 26+ DMG. The Mac package remains unsigned and unnotarized.

Current validation evidence is recorded in the [release manifest](https://github.com/wrestle-R/multi-codex/blob/main/docs/releases/v1.3.8-validation.json). Broader distro/desktop checks are tracked separately. Authenticated standalone isolation evidence is carried forward for the unchanged desktop version and backend launch construction.
