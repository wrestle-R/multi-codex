# Multi Codex 1.3.2 — macOS compatibility preview

This prerelease fixes account setup and current-desktop VS Code launch on Apple Silicon Macs running macOS 26 or newer. Native Spaces inventory and placement remain unavailable. Full release validation and signing/notarization remain pending; this preview does not replace the stable release.

- Discover Codex in current macOS VS Code extension layouts, including applications launched with a restricted PATH.
- Open the browser sign-in page with the native macOS browser opener and report browser-opening errors.
- Launch the native VS Code app with a short private alias for its profile data, avoiding the macOS Unix socket path limit. Existing profile data stays in its original location.
- Remove inherited Mac extension-host routing variables when opening isolated VS Code windows.
- Preserve the Linux executable, browser and desktop-placement paths.

Local checks cover frontend and Rust suites, native Keychain, importing an isolated copy of the current account, live usage limits, and actual VS Code renderer startup. Linux and macOS release builds are checked by GitHub Actions. The validation manifest records the remaining full-release gates without marking unperformed checks as passed.
