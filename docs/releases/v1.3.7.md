# Multi Codex v1.3.7

Choose the CLI terminal in Launch settings. Linux supports Konsole, GNOME Terminal, XFCE Terminal, xterm, Kitty, Ghostty, Alacritty and Foot; macOS supports Terminal, Kitty, Ghostty and Alacritty. Installed terminals are detected automatically. An explicit choice is honored, with a clear error if it becomes unavailable. Existing settings default to automatic selection.

Interactive launches now skip the VS Code extension’s helper binary, which can run usage queries while lacking a complete interactive CLI package. Install the full Codex CLI or select its executable in Launch settings. Account launches use the selected account’s saved credentials and isolated Codex/SQLite homes.

A small reminder at the top groups available usage resets that expire within 48 hours across accounts. It appears at most twice per local calendar day, with at least four hours between reminders, including across midnight and application restarts. View the grouped accounts and their expiry details, or dismiss the reminder. Expired, used, undated and stale reset details do not trigger reminders.

The Orange theme preview now uses dark colors in dark mode. Its light-mode preview is unchanged.

Saved accounts, credentials, conversations and existing preferences are preserved during updates. Packages: Linux x86_64 AppImage, DEB and RPM; Apple Silicon macOS 26+ DMG. The Mac package remains unsigned and unnotarized; follow the README’s explicit unsigned-install opt-in.
