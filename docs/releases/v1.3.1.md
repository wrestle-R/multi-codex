# Multi Codex 1.3.1 candidate

**Draft — publication blocked pending native macOS Spaces feasibility and packaged functional validation.**

- Fix repeated launches of the same profile and project: each launch uses a separate managed workspace descriptor, preventing VS Code from reusing an existing folder window. The original project and profile paths stay in place.
- Clear inherited VS Code CLI routing variables to preserve profile isolation when Multi Codex starts from an editor environment.
- Includes the ten-desktop Hyprland picker, installed application icons, responsive layouts, verified placement, serialized retries without duplicate launches, and automatic return to the main page after completion.
- Linux packages contain the Hyprland, GNOME extension and KDE bridge integrations. Apple Silicon packaging builds on macOS 26; native Spaces placement, real-Mac validation and signing/notarization remain required publication gates.

See [verification](v1.3.1-local-verification.md), [platform setup and compatibility](../platform-support.md), and [validation blockers](v1.3.1-validation.json). This candidate supersedes the unapproved 1.3.0 draft. The public release remains 1.2.3 until all agreed gates pass.
