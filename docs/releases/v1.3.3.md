# Multi Codex 1.3.3 — launch preferences preview

This candidate adds simpler Mac launching and saved launch preferences. Full packaged functional validation and Mac signing/notarization remain pending. This preview does not replace the stable release.

- On macOS, choosing a project folder launches VS Code directly without a desktop chooser.
- Launch settings now saves a preferred starting folder on both platforms.
- On Linux, uncheck **Show desktop picker before launching** to skip the desktop chooser; it remains enabled by default.
- Direct launch failures display an error and allow retrying.
- Existing account profiles, credentials, VS Code data and app identifier retain their existing locations. Older saved settings remain compatible.

Local validation: 44 frontend tests and 63 Rust tests passed; 3 live Linux environment tests were ignored. Production frontend build and formatting passed. Mac frontend behavior is simulated locally; native Mac checks and package builds run in GitHub Actions. Unperformed functional/signing checks remain recorded in the validation manifest.
