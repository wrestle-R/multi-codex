# Multi Codex 1.3.4 — settings and welcome preview

Preferred folder now has Browse, using the app's existing folder picker. Executable paths and Codex home live under Advanced, and the action is named Save settings. The desktop-picker preference appears only after positive Linux detection and is hidden on Mac.

New users get a simple welcome screen with subtle, reduced-motion-aware animation. Setup completion and detected apps are saved without relocating accounts. Existing accounts skip onboarding. Installations are checked again on startup, in settings and before launch.

The app-choice section is hidden unless both VS Code and the standalone app are detected. **VS Code is the only enabled launch target in this release.** Standalone/Both remain disabled pending authenticated isolation tests on Linux and Mac. Two signed-out Linux instances were isolated successfully; this does not prove two signed-in accounts are safe.

Mac GitHub runner checks now include native Keychain access, a disposable VS Code window, packaged-app window creation and restart, Unicode/spaced paths, an empty GUI PATH, and unchanged test account/config/settings fixtures. Signed-in end-to-end behavior and signing/notarization remain separate validation gates.

Account IDs, credential storage, profile paths and app identifier are unchanged. Linux and Mac installers are prepared as a draft preview; this does not replace the public stable release. See the validation manifest for outstanding packaged/signing checks.
