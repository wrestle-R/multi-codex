# Multi Codex 1.3.0 candidate

**Draft — publication blocked pending native macOS Spaces feasibility and packaged functional validation.**

- Responsive desktop picker shows all ten numbered Hyprland destinations, including empty desktops, with application icons, window counts, titles and current status. Other integrations use their actual desktop inventory.
- Hyprland uses session inventory and compatible native controls; GNOME uses the bundled protocol-1 extension; KDE Plasma 6 uses the embedded KWin bridge.
- Fix VS Code window identification when Electron rewrites Linux process arguments. Serialized placement verifies the selected destination, including current-desktop launches. Failed placement remains retryable without opening a duplicate window; successful launches close the picker and return to the main page.
- Launch settings supports custom VS Code/Codex executable paths and global Codex home. Existing managed profiles retain their locations.
- macOS candidate packaging targets Apple Silicon, macOS 26 and newer. Native Spaces previews and placement are not implemented or validated; this remains a mandatory release blocker.
- Automatic release publication is removed. Exact candidate hashes and functional test evidence must pass before publication.

See [local verification and screenshots](v1.3.0-local-verification.md), [platform compatibility and setup](../platform-support.md) and [validation status](v1.3.0-validation.json). Intel Macs and Windows are outside this candidate's support promise. Existing v1.2.3 downloads remain the public release until this candidate is cleared.
